🎯 Modul Ajar Interaktif • Fase F (Kelas XI)

Laboratorium Administrasi Sistem Jaringan

Pelajari konsep server Linux Debian 12 secara langsung melalui simulator terminal interaktif. Tanpa perlu install virtual machine, cukup buka tautan modul untuk mulai belajar dan mengerjakan misi mandiri.

Daftar Modul Praktikum

Pilih modul pembelajaran di bawah untuk membuka simulator dan materi.

5 Modul Tersedia
Modul 01

Remote Server (SSH)

Pengelolaan OpenSSH Server di Debian 12, login tanpa password via Public Key ed25519, hardening port & firewall UFW, transfer file (SCP/SFTP/Rsync), serta SSH Tunneling.

port 22 ed25519 tunneling
Buka Modul SSH
Modul 02

Web Server (Nginx)

Arsitektur asynchronous event-driven, konfigurasi Virtual Host Server Blocks, Reverse Proxy microservice, hardening banner identitas, dan sertifikat enkripsi SSL/HTTPS.

port 80/443 vhost reverse-proxy
Buka Modul Nginx
Modul 04

Firewall Server (UFW)

Konsep packet filtering, default deny policy, pembukaan port layanan (TCP/UDP), isolasi subnet IP, urutan rule, rate limiting brute-force, dan analisis ufw log.

packet-filter least-privilege port-rules
Buka Modul UFW
Modul 05

IPS Server (Fail2ban)

Pencegahan intrusi otomatis berbasis log, konfigurasi jail.local (bantime, findtime, maxretry), proteksi brute-force SSH & Web, manajemen unban IP, serta audit log.

anti-bruteforce jail.local unbanip
Buka Modul Fail2ban

🚀 Petunjuk Belajar Praktikum Mandiri

Gunakan simulator browser ini untuk mengasah keterampilan administrasi sistem jaringan Linux tanpa memerlukan aplikasi tambahan:

1. Baca Konsep & Alur

Pahami fungsi layanan, arsitektur protokol, dan alur konfigurasi sebelum mengeksekusi perintah.

2. Klik "Coba" ke Terminal

Tekan tombol Coba pada tabel perintah untuk memasukkan sintaks langsung ke terminal simulator.

3. Tuntaskan Misi & Kuis

Selesaikan 6 misi mandiri di tab Lab Terminal dan uji pemahaman kamu pada kuis pilihan ganda.
